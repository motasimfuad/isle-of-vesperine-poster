A travel poster for the Isle of Vesperine, an island that does not exist: a lantern spire on a sea arch, a white terraced village and a sun setting into a violet sea. It is drawn by a pure-standard-library Python program with its own anti-aliased rasteriser, a hand-built geometric typeface and a PNG encoder, and it writes the same 768×1024 PNG every run.

## Run it

```sh
python3 main.py   # writes /output/entry.png (set POSTER_OUT to write elsewhere)
```
